# Earlier editions

These are the optimized editions before edition 13. GitHub lists them alphabetically, which does not follow the edition numbers (`csArithmeticOpt-10` appears before `csArithmeticOpt-2`). The order below is the real one, newest first.

| Folder | What changes |
|---|---|
| [csArithmeticOpt-12](csArithmeticOpt-12) | `csInteger` |
| [csArithmeticOpt-11](csArithmeticOpt-11) | Names: `csRational`, `csReal` |
| [csArithmeticOpt-10](csArithmeticOpt-10) | Modular Fourier multiplication, Newton division at large sizes |
| [csArithmeticOpt-9](csArithmeticOpt-9) | Limbs in base 2^32, Toom-3 |
| [csArithmeticOpt-8](csArithmeticOpt-8) | Recursive division |
| [csArithmeticOpt-7](csArithmeticOpt-7) | Karatsuba |
| [csArithmeticOpt-6](csArithmeticOpt-6) | Base 10^19, not carried forward |
| [csArithmeticOpt-5](csArithmeticOpt-5) | Limbs in base 10^9 |
| [csArithmeticOpt-4](csArithmeticOpt-4) | Tables, stack temporaries, pointer walks |
| [csArithmeticOpt-3](csArithmeticOpt-3) | Tables, stack temporaries, pointer walks |
| [csArithmeticOpt-2](csArithmeticOpt-2) | Tables, stack temporaries, pointer walks |
| [csArithmeticOpt](csArithmeticOpt) | Forced inlining of the digit operations, still in base 10 |

The edition to use is [csArithmeticOpt-13](../csArithmeticOpt-13).
