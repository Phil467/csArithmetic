## ABOUT

This library was initially developed for educational purposes, to learn how to teach a computer to calculate using basic arithmetic rules. It includes addition, subtraction, multiplication and division, as well as modular arithmetic and gcd. It calculates on numerical strings grouped into two sets: reals (**`RNUMBER`**) and rationals (**`QNUMBER`**). Each operation contains small local optimizations. This base edition is the readable starting point. The optimized editions, which keep a formula such as `a = (b * c + d) / e - f` and put the faster algorithms under the operators, are published beside it in [Opt](Opt).

## A PROPOS

Cette bibliothèque est développée initialement dans un but éducatif, pour apprendre à un ordinateur à calculer à partir des règles de l’arithmétique. Elle possède l’addition, la soustraction, la multiplication et la division, ainsi que le calcul modulaire et le pgcd. Elle calcule sur des chaînes numériques regroupées en deux ensembles : les réels (**`RNUMBER`**) et les rationnels (**`QNUMBER`**). Chaque opération comporte de petites optimisations locales. Cette édition de base est le point de départ lisible. Les éditions optimisées, qui conservent une formule telle que `a = (b * c + d) / e - f` et placent les algorithmes plus rapides sous les opérateurs, sont publiées à côté, dans [Opt](Opt).
